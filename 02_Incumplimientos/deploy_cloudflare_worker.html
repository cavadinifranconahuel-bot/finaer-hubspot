FINAER · Incumplimientos — Wizard DNI Lookup
Guía de deploy — Cloudflare Worker
Para Tech Lead · Julio 2026

El wizard de Notificación de Incumplimientos consulta la base de datos de HubSpot en tiempo real para verificar el DNI del inquilino antes de que el notificante complete el formulario. Esta consulta requiere el token de la Private App de HubSpot.

La API de HubSpot bloquea llamadas directas desde el browser (política CORS) y el token no puede quedar expuesto en el código del frontend. Cloudflare Workers actúa de proxy server-side: el browser llama al Worker (sin token), el Worker llama a HubSpot (con token), el token nunca llega al browser.

1
Crear cuenta en Cloudflare Si no existe

Entrar a cloudflare.com y crear una cuenta gratuita. El plan Free incluye 100.000 requests diarios, más que suficiente para este uso.

2
Crear el Worker
En el dashboard de Cloudflare

Ir a Workers & Pages → Create → Create Worker. Asignar el nombre buscar-inquilino. La URL del Worker quedará como:
https://buscar-inquilino.TU-CUENTA.workers.dev

3
Pegar el código del Worker

En el editor que abre Cloudflare, reemplazar todo el contenido con el siguiente código:

worker.js — código completo 
export default {
  async fetch(request, env) {

    // CORS preflight
    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: cors() });
    }

    const url = new URL(request.url);
    const hsPath = url.pathname.replace(/^\/hs/, '') + url.search;
    const hsUrl  = 'https://api.hubapi.com' + hsPath;

    const body = request.method !== 'GET'
      ? await request.text()
      : undefined;

    const hsResponse = await fetch(hsUrl, {
      method:  request.method,
      headers: {
        'Authorization': `Bearer ${env.HUBSPOT_TOKEN}`,
        'Content-Type':  'application/json'
      },
      body
    });

    const data = await hsResponse.text();

    return new Response(data, {
      status:  hsResponse.status,
      headers: { ...cors(), 'Content-Type': 'application/json' }
    });
  }
};

function cors() {
  return {
    'Access-Control-Allow-Origin':  '*',
    'Access-Control-Allow-Methods': 'GET, POST, OPTIONS',
    'Access-Control-Allow-Headers': 'Content-Type'
  };
}

Hacer clic en Save and Deploy.

4
Registrar el secreto HUBSPOT_TOKEN

El Worker lee el token desde una variable de entorno secreta. Esto evita que el token quede expuesto en el código.

Desde el dashboard del Worker

Ir a Settings → Variables and Secrets → Add variable.

TipoSecret
NombreHUBSPOT_TOKEN
ValorToken de la Private App "Claude Code - FINAER"

Hacer clic en Save. El valor queda encriptado y nunca es visible nuevamente.

5
Actualizar la URL en el wizard

En el archivo 02_Incumplimientos/notificacion-incumplimiento.html, hay una sola línea que define el endpoint según el entorno. Reemplazar la URL de producción con la del Worker:

Antes
const HS_BASE = location.hostname === 'localhost'
  ? 'http://localhost:3001/hs'
  : 'https://api.hubapi.com';
Después — reemplazar con la URL real del Worker
const HS_BASE = location.hostname === 'localhost'
  ? 'http://localhost:3001/hs'
  : 'https://buscar-inquilino.TU-CUENTA.workers.dev/hs';

Reemplazar TU-CUENTA con el subdominio asignado al crear la cuenta en Cloudflare.

Notas de seguridad
  • El token nunca llega al browser. Vive encriptado en Cloudflare y solo el Worker tiene acceso en tiempo de ejecución.
  • CORS abierto (*). Cualquiera que conozca la URL del Worker puede hacer llamadas. Para mayor restricción, se puede limitar el origen al dominio de la landing (landing.finaersa.com.ar) una vez en producción estable.
  • Rate limiting. Cloudflare Free incluye protección básica. Para uso intensivo, activar Rate Limiting desde el dashboard.
  • El token usado es el de la Private App "Claude Code - FINAER" (portal EU1 · 145725856). Rotar el token si se sospecha exposición.
